# Telegram Survey Bot

یک ربات تلگرام برای پرسیدن سوالات نظرسنجی و ذخیره پاسخ‌ها، بدون هیچ‌گونه دیتابیس محلی. تمام داده‌ها در کانال‌های تلگرام نگهداری می‌شوند.

## ✨ امکانات

- افزودن/حذف سوال توسط ادمین
- نمایش لیست سوالات
- پاسخ‌دهی مرحله‌به‌مرحله برای کاربران
- پیش‌نمایش پاسخ‌ها و امکان ویرایش
- ارسال پاسخ نهایی با آیدی عددی کاربر به کانال جواب‌ها
- بدون ذخیره‌سازی محلی (فقط RAM برای نشست‌های فعال)

## 🚀 راه‌اندازی

1. یک ربات از [@BotFather](https://t.me/BotFather) بسازید و توکن را بردارید.
2. از [my.telegram.org](https://my.telegram.org) یک اپلیکیشن بسازید و `API_ID` و `API_HASH` دریافت کنید.
3. دو کانال تلگرام بسازید؛ یکی برای سوالات، یکی برای جواب‌ها.
4. ربات را در هر دو کانال **ادمین** کنید.
5. آیدی عددی خودتان و آیدی‌های دو کانال را به دست آورید (از [@getidsbot](https://t.me/getidsbot)).
6. فایل `.env` را بر اساس `.env.example` بسازید و مقادیر را وارد کنید.
7. نصب پیش‌نیازها:
   ```bash
   pip install -r requirements.txt
