# Telegram Survey Bot

ربات نظرسنجی تلگرام با Pyrogram که سوال‌ها را در یک کانال و پاسخ‌های نهایی را در کانال دیگری نگهداری می‌کند.

## امکانات

- افزودن، حذف و نمایش سوال‌ها توسط ادمین
- پاسخ‌دهی مرحله‌ای
- پیش‌نمایش پاسخ‌ها
- ویرایش پاسخ قبل از ثبت نهایی
- ارسال پاسخ‌ها به کانال جواب‌ها
- نگهداری نشست کاربران در RAM

## راه‌اندازی

1. ربات را با BotFather بسازید.
2. از my.telegram.org مقدارهای `API_ID` و `API_HASH` را بگیرید.
3. دو کانال برای سوال‌ها و جواب‌ها بسازید.
4. ربات را در هر دو کانال ادمین کنید.
5. `.env.example` را به `.env` کپی و مقدارها را تنظیم کنید.
6. وابستگی‌ها را نصب کنید:

```bash
pip install -r requirements.txt
```

7. اجرا:

```bash
python -m bot.main
```

## دستورات ادمین

```text
/add_question متن سوال
/remove_question شماره
/list_questions
```

## نکات

- `ADMIN_ID` باید آیدی عددی ادمین باشد.
- `QUESTIONS_CHANNEL_ID` و `ANSWERS_CHANNEL_ID` معمولاً با `-100...` شروع می‌شوند.
- نشست‌ها در RAM هستند و با restart شدن برنامه از بین می‌روند.
- متن پاسخ‌های کاربران با HTML escape می‌شود تا formatting تلگرام خراب نشود.
- پاسخ‌های خیلی بزرگ به چند پیام تقسیم می‌شوند.

## خطای فعلی پروژه

خطای `TypeError: command() missing 1 required positional argument: 'commands'` به این دلیل بود که `filters.command()` بدون نام command فراخوانی شده بود. هندلر عمومی متن نیازی به آن فیلتر ندارد و اکنون پیام‌های شروع‌شده با `/` را خودش نادیده می‌گیرد.
